## Featured Projects

### 1. HR Recruitment Analytics Dashboard

**Power BI · SQL · DAX · Power Query**

[View Project on GitHub →](https://github.com/Inder616/Recruitment-Funnel-Hiring-Analytics-Dashboard)

Developed an interactive recruitment analytics dashboard to monitor the hiring process across **408 manpower requisitions**.

**Key analysis:**
- Recruitment funnel and stage-wise conversion.
- Open versus closed requisitions.
- Candidate and offer-letter tracking.
- Offer acceptance and joining analysis.
- Recruitment turnaround time.
- Position and recruiter-level performance.

**Key Insight:** The average time from requisition to offer was approximately **21 days**, highlighting an important area for recruitment process improvement.

### 2. Patient Appointment Delay & No-Show Analysis

**Python · Pandas · Power BI · DAX**

[View Project on GitHub →](https://github.com/Inder616/Patient-Appointment-Delay-No-Show-Analysis)

Analysed **111K+ healthcare appointment records** to investigate appointment attendance patterns and factors associated with patient no-shows.

**Key analysis:**
- Data cleaning and validation using Python.
- Waiting-time and appointment-delay analysis.
- Patient segmentation.
- No-show rate analysis.
- Trends across patient and appointment characteristics.
- Interactive KPI reporting in Power BI.

**Key Insight:** Appointments with longer waiting periods showed higher no-show rates, indicating an opportunity to improve appointment scheduling and reminder strategies.
